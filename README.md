# WhatsApp Automation Dashboard 🚀

A Python-based desktop application built using CustomTkinter that automates WhatsApp messaging through a modern GUI.

---

## ✨ Features

- Bulk WhatsApp Messaging
- CSV Contact Upload
- Personalized Messages
- Group Messaging
- Recurring Scheduling
- Login & Registration System
- Password Hashing
- Remember Me Functionality
- Multiple User Support
- Emoji Picker
- Contact Search
- Attachment Upload
- Progress Tracking
- Export Logs to Excel
- Theme Switching
- Scrollable Modern Dashboard UI

---

## 🛠 Technologies Used

- Python
- CustomTkinter
- Pandas
- PyWhatKit
- Pillow
- Schedule
- JSON
- OpenPyXL

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/your-username/Automated_Whatsapp_Tool.git
```

Move into project folder:

```bash
cd Automated_Whatsapp_Tool
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
python main.py
```
